# Skill-GUI

> 여러 AI 코딩 에이전트(Claude Code, Codex 등)의 스킬을 한 화면에서 보고, 배포하고, 찾고, 비교하는 데스크톱 앱

## 왜 만드나

Claude Code, Codex 같은 AI 코딩 에이전트의 스킬·플러그인 생태계가 빠르게 커지면서 다음 문제가 생겼다.

- 설치하고 시간이 지나면 **스킬이 무슨 일을 하는지 잊어버린다.**
- 스킬이 많아지면 **중복되거나 안 쓰는 스킬**을 찾기 어렵다.
- 같은 스킬을 여러 에이전트에서 쓰려면 **폴더마다 손으로 복사**해야 하고, 고치면 버전이 어긋난다.
- 설명이 `SKILL.md`와 스크립트에 흩어져 있고, 기존 도구(`/skill-doctor`, Skills Janitor, skillvitals, skillscope 등)는 **텍스트·CLI 출력** 중심이라 한눈에 비교하기 힘들다.

Skill-GUI는 이 흐름을 **카드·목록·상세 화면**으로 옮겨, 스킬을 "무엇을 하고 언제 쓰는지" 기준으로 이해하고 정리하게 한다.

## 핵심 기능

### 1. 에이전트별 전역 스킬 / 프로젝트별 스킬 확인
- 각 에이전트의 **전역 스킬 경로**(예: `~/.claude/skills/`, 플러그인 폴더)와 **프로젝트 스킬 경로**(예: `<project>/.claude/skills/`)를 스캔
- 에이전트 × 범위(전역 / 프로젝트) 기준으로 스킬 목록 표시
- `SKILL.md`의 이름·설명·출처, 포함된 스크립트 정보를 파싱해 카드로 보여줌
- LLM으로 기능·사용 상황을 한국어로 요약하고 카테고리 분류
- 세션 로그를 분석해 **관측된 사용 횟수와 마지막 사용일** 표시
- 메모, 비활성화, 삭제 (실행 전 변경 대상·영향 확인)

### 2. 한 스킬을 여러 에이전트에 배포·동기화
- 스킬 하나를 골라 여러 에이전트(Claude Code, Codex 등)와 프로젝트에 한 번에 배포
- 원본이 바뀌면 배포된 사본과의 **차이(diff)를 표시**하고 동기화
- 에이전트마다 다른 스킬 형식이 있으면 변환 규칙 적용

### 3. 스킬 검색 및 업데이트 확인
- 이름·설명·요약·카테고리로 로컬 스킬 검색, 미사용 후보 필터
- 마켓플레이스·레지스트리·GitHub 등 원격 소스에서 새 스킬 검색 및 설치
- 설치된 스킬의 **원본 버전과 비교해 업데이트 여부 확인** 및 업데이트

### 4. 스킬 랭킹 확인
- 원격 소스의 **별점(스타), 다운로드 수** 등으로 인기 스킬 랭킹 표시
- 카테고리별 랭킹, 내가 설치한 스킬과의 비교

## 사용 시나리오

1. 앱을 처음 열면 각 에이전트의 스킬·플러그인 경로를 스캔해 목록을 만든다.
2. 에이전트·범위별로 스킬을 보고, 한국어 요약과 카테고리를 훑는다.
3. 검색·필터로 미사용 후보를 찾고, 세션 기록의 관측 기간과 마지막 사용일을 확인한다.
4. 상세 화면에서 `SKILL.md` 원문과 스크립트를 보고 메모를 남긴다.
5. 자주 쓰는 스킬은 다른 에이전트에도 배포하고, 안 쓰는 스킬은 대상을 확인한 뒤 비활성화·삭제한다.
6. 업데이트가 있는 스킬을 갱신하고, 랭킹에서 새 스킬을 찾아 설치한다.

## 주의할 점 (설계 원칙)

- **"기록 없음" ≠ "안 씀"**: Claude Code 세션 기록은 기본적으로 30일 뒤 삭제될 수 있다. 로그가 확인된 기간을 함께 표시하고, 기간 밖 사용은 추정하지 않는다.
- **파괴적 작업은 미리보기 후 실행**: 비활성화·삭제·동기화는 변경될 파일과 영향을 먼저 보여준다. 플러그인 공유 파일이나 사용자 설정이 손상되지 않게 하고, 실패 시 데이터 불일치를 막는다.
- **로컬 파일 외부 전송 주의**: LLM 요약 시 민감한 로컬 파일이 외부로 나갈 수 있으므로 전송 범위를 사용자에게 알린다.
- **경로·로그 형식 변화 대응**: 에이전트 업데이트로 경로나 로그 형식이 바뀌면 수집이 누락될 수 있다. 실패한 항목은 숨기지 않고 표시한다.
- **로컬 서버 접근 통제**: 로컬 서버를 띄운다면 외부 접근을 막는다.

## 범위

| 포함 | 제외 (초기 버전) |
|---|---|
| 한 기기, 단일 사용자 | 계정 가입, 팀 협업 |
| 로컬 스킬·플러그인 스캔 | 원격 동기화(클라우드 백업) |
| 데스크톱 앱 | 모바일·웹 |

## 핵심 지표

- 첫 스캔에서 발견한 스킬 중 이름·출처·설명을 표시할 수 있는 비율
- 요약·카테고리 생성 성공률
- 스킬 확인 후 검색·필터·메모·배포·비활성화·삭제로 이어지는 비율
- 로그 확인 기간과 관측된 호출의 귀속률 ("미사용" 표시 검증용)

목표치는 시범 사용 후 정한다.

## 로드맵

- [ ] 2단계: 한국어 요약·카테고리, 세션 로그 기반 사용 현황
- [ ] 3단계: 메모·비활성화·삭제 (미리보기 포함)
- [ ] 4단계: 다중 에이전트(Codex 등) 지원, 배포·동기화
- [ ] 5단계: 원격 검색·업데이트 확인·랭킹
