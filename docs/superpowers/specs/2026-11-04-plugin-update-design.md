# 플러그인 업데이트 설계 (feat/skill-scan)

## 목적
"업데이트 필요" 탭에서 새 버전이 나온 플러그인만 보여주고, 앱에서 바로 업데이트한다. README 핵심 기능 3 "설치된 스킬의 원본 버전과 비교해 업데이트 여부 확인 및 업데이트".

## 결정 사항 (사용자 결정)
- 최신 버전은 인터넷에서 확인한다.
- 업데이트 버튼까지 만든다.
- 확인과 업데이트 모두 Claude Code 명령을 쓴다. 파일을 직접 받거나 복사하지 않는다.

## 범위
- 대상: 설치된 플러그인(`installed_plugins.json`). 단위는 스킬이 아니라 플러그인이다(업데이트가 플러그인 단위라서).
- 제외: 전역 스킬(`~/.claude/skills`). 버전 정보가 없다.

## 동작
1. 탭을 열면 "업데이트 확인" 버튼과 마지막 확인 시각을 보여준다. 앱을 켤 때 자동으로 확인하지 않는다.
2. "업데이트 확인"을 누르면 `claude plugin marketplace update`로 마켓 복사본을 인터넷에서 새로 받는다. 진행 중에는 버튼을 막고 진행 표시.
3. 이어서 플러그인마다 설치 버전과 최신 버전을 비교한다.
   - 최신 버전: 마켓 `.claude-plugin/marketplace.json`의 해당 항목 `version`, 없으면 항목 `source`가 경로(문자열)일 때 `<마켓>/<source>/.claude-plugin/plugin.json`의 `version`.
   - 버전을 알 수 없고 항목 `source`에 `sha`가 있으면, 설치 기록의 `gitCommitSha`와 비교한다(커밋 앞 7자리로 표시).
   - 둘 다 없으면 "확인할 수 없음"으로 따로 표시한다(숨기지 않는다).
   - 설치 값과 최신 값이 다르면 "업데이트 필요".
4. 목록 항목: 플러그인 id, `현재 → 최신`, 포함된 스킬 수, "업데이트" 버튼.
5. "업데이트"를 누르면 확인 창: `<id>`를 `현재 → 최신`으로 업데이트합니다. Claude Code를 다시 시작해야 적용됩니다. [취소] [업데이트]
6. 확인하면 `claude plugin update <id> --scope <scope> --json` 실행. 성공하면 다시 스캔하고 목록에서 빠진다. 실패하면 항목 아래에 이유를 보여준다. 추가 확인이 필요한 플러그인(명령형 설치)은 "Claude Code에서 직접 업데이트해 주세요"로 안내한다.
7. `claude` 명령을 찾지 못하면 "Claude Code 명령(claude)을 찾지 못했습니다"를 보여준다. 찾는 순서: macOS는 로그인 셸(`/bin/zsh -lc 'command -v claude'`), Windows는 `where claude`.

## 접근 방식
1. **Claude Code 명령 사용 (선택)**: 모든 마켓 형식을 Claude Code가 처리한다. 우리 코드는 비교와 화면만.
2. 확인은 GitHub에서 직접, 업데이트만 명령: GitHub 마켓만 지원, 코드가 늘어난다.
3. 전부 직접: Claude Code 로직을 따라 해야 하고 실패 시 플러그인이 깨질 수 있다.

## 주의
- 업데이트는 사용자 파일을 바꾸는 일이라 확인 창 없이 실행하지 않는다.
- 명령 실행 결과(종료 코드, 출력)는 실패 시 그대로 보여준다.
- 테스트는 명령 실행을 바꿔 끼울 수 있게 해서 실제 `claude`를 부르지 않는다.

## 빌더에게 맡기는 것
화면 세부 모양(시안 "찾기·업데이트" 참고), 마지막 확인 시각 보관 방식(앱 실행 중에만 기억해도 된다).
