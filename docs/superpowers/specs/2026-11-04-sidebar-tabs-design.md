# 사이드바 탭 설계 (feat/skill-scan)

## 목적
시안(https://claude.ai/artifact/STvot9BocgrsUZXwDAWF9f "스킬 목록")대로 왼쪽 사이드바 탭으로 화면을 오간다. 앞으로 만들 화면(Codex, 업데이트, 미사용 후보, 찾기·랭킹)이 들어갈 자리를 먼저 만든다.

## 탭 구성
- **에이전트**: Claude Code(스킬 개수 표시), Codex
- **정리**: 업데이트 있음, 미사용 후보, 찾기·랭킹
- 화면이 없는 탭(Codex, 업데이트 있음, 미사용 후보, 찾기·랭킹)은 누르면 "아직 준비 중입니다" 화면. 개수는 비운다. (사용자 결정)

## 결정 사항
- 필터(전체/전역/플러그인/꺼짐)는 사이드바에서 빼고, Claude Code 화면 제목 아래 작은 버튼 줄로 옮긴다. (사용자 결정)
- 브랜치는 `feat/skill-scan`에서 이어 간다. (사용자 결정)
- 상세 화면은 지금처럼 화면 전체를 덮는다.

## 접근 방식
1. **공통 틀 하나 (선택)**: `lib/ui/app_shell.dart`가 사이드바 탭과 오른쪽 내용 영역을 갖고, 선택한 탭에 따라 내용을 바꾼다. `SkillListPage`는 사이드바를 빼고 내용만 남긴다.
2. 화면마다 사이드바를 넣기: 사이드바가 화면 수만큼 중복된다. 뺐다.

## 하지 않는 것
Codex 스캔, 업데이트·미사용 판정, 찾기, 랭킹 기능. 탭과 "준비 중" 화면만 만든다.

## 빌더에게 맡기는 것
탭 아이콘, 버튼 줄 모양 등 세부 디자인(시안 참고). 탭 선택 상태를 접근성으로 알리고, 누를 수 있는 영역은 44px 이상.

## 2026-11-04 변경 (사용자 요청)
- 탭은 그룹 제목 없이 `내 스킬` / `업데이트 있음` / `검색` 세 개.
- `에이전트` 그룹을 `내 스킬` 탭 하나로 합치고, Claude Code·Codex는 내 스킬 화면 안의 필터(첫 줄: 전체 / Claude Code / Codex)로 옮겼다. 둘째 줄은 기존 필터(전체 / 전역 / 플러그인 / 꺼짐).
- `미사용 후보` 탭과 `정리` 제목은 지웠다. `찾기·랭킹`은 `검색`으로 바꿨다.
- Codex 필터는 Codex 스캔을 만들기 전까지 "아직 준비 중입니다". (빌더 판단)
- 상세 화면 뒤로 버튼 문구도 `내 스킬`로 바꿨다.
