## 2026-11-05

**완료한 일**
- 스킬 상세 진입 시 `SKILL.md`와 스킬 폴더의 파일 목록을 Claude API로 분석해, 한국어 설명을 자동 표시하는 기능을 구현했다.
- 공통 분석 항목을 `이 스킬은`, `이럴 때 사용`, `처리 방식`, `필요한 입력·준비`, `결과`, `포함된 구성`, `주의할 점`으로 정했다. 원문 근거가 없는 항목은 표시하지 않는다.
- 공통 항목으로 설명할 수 없고 빠지면 오해를 낳는 정보만 `특이사항`으로 추가하도록 서버 프롬프트와 응답 검증을 구성했다.
- Flutter 앱에는 분석 API 클라이언트와 원문 변경 시 무효화되는 로컬 캐시를 추가했다. 원본 `SKILL.md`는 수정하지 않는다.
- relay에 `/api/skill-analysis`를 추가했다. API 키는 `ANTHROPIC_API_KEY` 환경 변수에서만 읽고, 입력 길이 제한·오류 처리·Claude 응답 JSON 검증을 포함한다.
- `flutter analyze`, 관련 Flutter 테스트 11개, relay TypeScript 검사를 통과했다. Windows 디버그 빌드 자산도 갱신했다.

**다음 할 일**

- 실제 스킬에서 Claude가 JSON 앞뒤에 설명을 붙일 때도 분석 결과를 읽도록 서버 파서를 보완했다. 수정 커밋 `1189ff8`을 `feat/skill-analysis-ko`에 push했고, relay TypeScript 검사도 통과했다. 최신 Preview 재배포가 필요하다.

## 2026-11-08

**완료한 일**
- 필터의 카테고리 체크박스 UI를 새로 만들었다. 기본 `Checkbox` 대신 둥근 사각형 박스를 직접 그렸다. 체크는 앱 메인 파랑(`0xFF0064D1`) 채움에 흰 체크, 미체크는 반투명 흰색(70%), 호버는 연한 파랑 체크 아이콘으로 구분한다.
- "선택 해제" 버튼이 선택 여부와 관계없이 자리를 차지하도록 바꿨다. 선택할 때 아래 목록이 움직이지 않는다.
- 필터 하단의 "분석 중인 스킬 N개는 끝나면 반영됩니다." 문구를 뺐다.
- 수정 파일은 `lib/features/skill_analysis/widgets/category_filter_panel.dart` 하나다. `flutter analyze`는 통과했고, 앱 실행 확인은 아직 못 했다.
- "내 스킬" 카드에 한국어 한 줄 요약과 카테고리 배지(최대 3개)를 붙였다. 스캔 후 캐시에 없는 스킬을 3개씩 차례로 분석하고, 목록과 상세가 같은 분석 결과를 쓴다.
- 카테고리는 claudeskills.info/ko/skills의 61개 목록을 앱(`skill_categories.dart`)과 relay에 넣었다. 다시 스캔 옆 필터 아이콘을 누르면 61개 체크박스가 펼쳐지고, 체크한 카테고리의 스킬만 목록에 남는다.
- 상세 화면을 개편했다: 이름 아래 경로·버전을 흐린 보조 정보로, 출처 배지 옆에 카테고리, 이름 줄 오른쪽 끝에 `GitHub로 가기`(저장소 메인), 맨 위 `설치방법`(명령어 복사), 항목명 정리(`개요`, `결과물`), `포함된 구성`·`주의할 점` 접기, 영어 설명·`SKILL.md 원문`·`필요한 입력·준비`·특이사항 제거.
- 출처는 플러그인 마켓 정보와 `npx skills -g` 설치 기록(`~/.agents/.skill-lock.json`)에서 찾는다. 기록이 없는 전역 스킬(`hallmark`, `impeccable`)은 "출처 없음"으로 둔다.
- relay 버그 3개를 고쳤다: 요약·카테고리 응답 추가, JSON 앞뒤 설명 무시(`1189ff8`과 같은 수정이 이 브랜치에 빠져 있었음), `max_tokens` 1800 → 8000(큰 스킬은 응답이 잘려 항상 실패했음).
- 파일이 1,631개인 스킬이 "내용이 너무 크다"로 실패해, 앱에서 파일이 많은 폴더와 이미지 파일을 묶어 보내도록 했다(300줄 이하). 앱의 분석 대기 시간은 90초로 늘렸다.
- 캐시 형식 버전을 2로 올려, 카테고리가 없는 이전 분석은 다시 분석한다.
- 로컬 임시 relay로 실제 스킬 3개(`hallmark`, `impeccable`, `design-taste-frontend`) 분석과 카테고리 표시를 확인했다.
